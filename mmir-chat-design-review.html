Open WebUI benchmark → MMIR interpretation

Use Open WebUI as a product benchmark, not as MMIR's codebase: chat, history, model picker, tools/functions, knowledge, pipelines, auth and admin are strong patterns. MMIR's own moat is trusted orchestration across nodes.

Free LLM route

No, it is not technically difficult to run free LLMs in chat. The hard part is reliability, latency, privacy and cost control.

Best no-cost MVP

MMIR Local Node + Ollama. User hardware runs inference, prompts stay local, and MMIR uses a stable chat contract.

Best instant demo

Keep the free bootstrap route and add optional free-provider adapters behind api.mmir.ai with strict rate limits.

Browser model path

Possible with WebGPU/WASM small models, but downloads, heat, battery and compatibility make it secondary.
