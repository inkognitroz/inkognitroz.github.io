Launch checklist

  • Open WebUI is reachable on HTTPS or a trusted HTTP test URL.
  • Ollama listens privately on the server, not as a public internet API.
  • A default model such as gemma3:4b is pulled and visible inside Open WebUI.
  • Authentication is configured in Open WebUI before sharing the URL.
  • No API keys, OCI credentials, or bearer tokens are committed to this static site.

Static/frontend boundaries

GitHub Pages can safely host links, guidance, public model metadata, and local browser configuration. Secrets, provider API keys, private documents, and RAG indexing belong behind a backend or a protected service.

This portal deliberately does not proxy chat requests. It keeps the frontend static while making the backend target explicit.
