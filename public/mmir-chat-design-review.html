Open WebUI Benchmark → MMIR Interpretation

Open WebUI has useful product patterns: one interface for providers, multi-model chat, knowledge, model presets, tools, pipelines, authentication and admin. MMIR should use that as a UX benchmark while staying clean-room and control-plane native.

Keep visible

  • Chat transcript and composer
  • New chat/search/sidebar
  • Current model/node chip
  • Send, attach, voice later
  • Clear online/offline state

Make subtle

  • Node picker
  • Model comparison
  • Tools and MCP servers
  • Knowledge/RAG
  • Workflows and automations

Keep behind admin

  • Provider keys and secrets
  • Billing/spend policy
  • Org and RBAC setup
  • Raw telemetry
  • Infrastructure/runtime controls

Free LLM Route

It is not hard to wire a free LLM into chat. The hard part is making it reliable, fast, private and cost-safe for real users.

Best no-cost MVP

Use MMIR Local Node + Ollama. The user pays with their own CPU/GPU, prompts stay local, and MMIR exposes a stable `/chat/completions` contract.

Best instant demo

Keep the current free bootstrap route, then add optional free-provider adapters behind `api.mmir.ai` with strict rate limits and no surprise spend.

Browser model path

Possible with WebGPU/WASM and small models, but large downloads, mobile heat/battery and inconsistent browser support make it secondary.
