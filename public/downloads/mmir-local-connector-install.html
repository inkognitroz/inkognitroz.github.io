Install Connector

The connector turns Mac, Windows, Linux, Raspberry Pi, VMs and edge machines into private MMIR nodes. It runs on 127.0.0.1:3000, connects to Ollama on the same machine, and lets mmir.ai chat with local models through the MMIR API contract. This page reads the release manifest before promoting platform artifacts, so it never links a fake DMG.

Free by defaultNo paid cloud, provider route or managed compute starts from these installers.
Private nodeThe connector binds to 127.0.0.1 unless the local owner changes policy.
Pair before controlModel, chat and tunnel routes require local pairing before use.
Return to proofInstallers reopen MMIR with mmir_local_return=1 so health and model proof resume automatically.
