# AI workflow (SaaS Fabric)

1. Save tasks/prompts in `Prompt Inbox` in `public/content.json`.
2. Paste a prompt into GitHub Issues, Copilot, Codex, Claude Code, or ChatGPT.
3. Ask for PR-focused updates to content, docs, and static assets.
4. Review generated pull requests manually.
5. Merge and deploy to GitHub Pages.

Use AI as an implementation assistant, not an automatic deployment authority.
Do not automate unsafe browser-based git commits.
